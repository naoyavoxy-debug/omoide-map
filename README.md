# 2人の思い出マップ Ver.1

スマホで使える日本旅行の思い出アプリです。

## 使い方
1. `index.html`, `style.css`, `app.js` を同じ場所に置きます。
2. GitHub Pages に公開すればスマホから使えます。
3. 都道府県をタップして、日付・メモ・写真を保存します。

## Ver.1 の保存について
データはブラウザの localStorage に保存されます。
そのため、この版では別のスマホとは自動共有されません。
写真を大量に保存するとブラウザの保存容量に達する場合があります。

次の版で、2人のスマホで同じ思い出を共有するクラウド保存に発展できます。
